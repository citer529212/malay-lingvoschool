# Малайская лингвошкола

Справа вверху доступен переключатель «Малайский / Индонезийский», сохраняющий выбранный раздел. Индонезийская версия (`indonesian.html`) использует отдельные ключи прогресса, словаря, мастерской и тренажёра. Пока ожидаются учебник, полный словарь и аудио пользователя, опубликованы три авторских вводных примера, небольшой словарь, четыре сценария практики перевода и озвучивание голосом браузера id-ID при его наличии. Это не индонезийская редакция малайского учебника; исходные материалы малайской школы сохранены.

Индонезийские новости берутся из RSS ANTARA в четырёх рубриках. Пересборка вводной версии: `python3 scripts/build_indonesian.py`; проверка: `python3 scripts/verify_indonesian.py`. Общая логика берётся из `school.js`, отдельное оформление содержимого — из `scripts/indonesian-ui.js`.

Сайт: https://citer529212.github.io/malay-lingvoschool/

Главная страница знакомит со школой и ведёт к учебнику, аудированию и военному переводу; пример перевода по нажатию работает прямо на ней.

Основной курс построен по предоставленному учебнику Т. В. Дорофеевой и Е. С. Кукушкиной «Учебник малайского (малайзийского) языка» (Москва, 2006).

- Введение, 9 вводно-фонетических и 31 основной урок.
- Тексты, диалоги, грамматика, упражнения с сохранением ответов, собственные переводы и сканы для сверки.
- 147 предоставленных аудиозаписей: скорость 0,75–1,5×, возврат на 10 секунд, повтор, запоминание позиции.
- Словарь Offline Lite v6.18: 50 319 статей, перевод слова по нажатию, личные слова и карточки.
- Прежний тренажёр сохранён в military.html под вкладкой «Военный перевод». Исходный ключ localStorage и все его учебные материалы сохранены.
- Новости и помощник перевода остаются в отдельной вкладке.

## Текст учебника

PDF является сканом. Распознанный текст может содержать ошибки, особенно в таблицах и транскрипции. В каждом фрагменте доступна исходная страница. Свободные ответы не имеют автоматической оценки; кнопка Google открывает внешнюю сверку, которая не является авторским ключом.

Распознанные страницы хранятся в `sources/book-ocr.json`; разметка курса воспроизводится командой `python3 scripts/build_course.py`. Проверка материалов: `python3 scripts/verify_course.py`.

## Публикация

GitHub Actions проверяет файлы, обновляет RSS Astro AWANI и публикует статический сайт на GitHub Pages. Новости обновляются по часовому расписанию с возможными задержками планировщика. Ручной запуск: Actions → Publish school → Run workflow.

## Данные пользователя

Прогресс хранится в localStorage браузера. Экспорт на вкладке «Прогресс» включает учебник, слова, военный тренажёр и новостную мастерскую. При смене браузера импортируйте резервную копию.

По кнопке перевода текст отправляется в MyMemory, по ссылке Google — в Google Переводчик. Бесплатный сервис ограничивает суточную квоту. Словарь для нажатий работает локально после загрузки.
