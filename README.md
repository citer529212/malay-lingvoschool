# Малайская лингвошкола

Тренажёр ГИА по малайскому языку: 34 текста, 11 диалогов, 14 тем, 70 терминов, карточки, тесты и экзамен с таймером.

Отдельная вкладка «Новости и перевод»: новости Astro AWANI, загрузка TXT, собственный перевод, подсказки из словаря, MyMemory MS ↔ RU и переход в Google Переводчик.

Прогресс хранится в localStorage браузера. При переносе с другого адреса воспользуйтесь экспортом и импортом во вкладке «Прогресс».

GitHub Actions обновляет новости каждый час (возможны задержки планировщика), а затем публикует сайт на GitHub Pages. Ручной запуск: Actions → Publish school → Run workflow.

По кнопке перевода текст отправляется в MyMemory, по ссылке Google — в Google Переводчик. Бесплатный перевод зависит от квот сервиса.
